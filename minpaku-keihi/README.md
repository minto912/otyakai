# minpaku-keihi — 民泊 経費精算

作業料と立替金を記録して、ルルさん提出用の**経費精算書 PDF** を出すための 1 ファイル完結ツールです。
`index.html` だけで動きます。ビルドも依存ライブラリもサーバも要りません。

お茶会サイトとは独立したページです。GitHub Pages では `/minpaku-keihi/` で開きます。

## 使う

`index.html` をブラウザで開くだけです。スマホでも使えます。

1. **対象期間・宛先** — 月と対象期間（既定は月初〜月末）、担当名と宛先を入れる
2. **記録を追加** — 種類 → 日付 →（部屋／作業料／立替額）→ メモ、で 1 件ずつ足していく
3. **レシート写真** — 立替のある記録に「レシート写真」ボタンが出る。撮って選ぶと PDF の巻末に付く
4. **振込先** — 一度入れれば保存され、精算書に載る
5. **書き出す** — 「精算書PDFを作る」で印刷ダイアログ →「PDFで保存」

## 記録の種類

既定は 掃除点検 ¥1,000 / 買い物 ¥1,000＋立替 / 荷物受け取り ¥1,000 / 荷物預かり ¥2,000 です。
「＋ 種類を追加」で足せます。追加のときに聞かれるのは次の 3 つです。

1. 名前（例：自転車代理購入）
2. 作業料（円）
3. **立替（自分で払った実費）も記録するか** — 「する」にすると、記録するときに
   **作業料と立替の両方**を入力でき、レシート写真も付けられます
4. 部屋（マンション）も選ぶか

たとえば「自転車代理購入・作業料 ¥2,000・立替あり」にしておけば、
自転車の代金 ¥18,500 を立替として入れて、合計 ¥20,500 として精算書に載せられます。
作業料は記録するときに変えられるので、同じ種類でも金額が違う回に対応できます
（空にすると種類の既定額が入ります）。

追加した種類は ✕ で消せます（過去の記録は消えません）。

## データの持ち方

| もの | 保存先 | 消えるとき |
| --- | --- | --- |
| 記録・振込先・担当名・種類・対象期間 | ブラウザの localStorage | 履歴消去、別の端末・別ブラウザ |
| レシート写真 | メモリのみ | **画面を閉じたら消える** |

写真は保存されないので、**撮った当日に PDF まで書き出してください**。
記録そのものは「バックアップを保存」でファイル 1 個に書き出せます（写真は含まれません）。
機種変更やデータ消去に備えて、月 1 回の書き出しがおすすめです。

## 元の版から足したところ

- 追加した種類でも**立替を扱えるようにした**。元の版で立替を持てるのは「買い物」だけで、
  自転車の代理購入のような「作業料＋実費」の記録ができなかった
- 立替のある種類では**作業料も記録するときに入力できる**ようにした
- 部屋・作業料・立替は組み合わせが変わるので、見出しの番号（③④⑤）は出ている欄だけで振り直す
- レシート写真と PDF 巻末の添付を、買い物固定ではなく**立替のある記録すべて**に広げた

## 元の版から直したところ

| 直したこと | 元の挙動 |
| --- | --- |
| 記録の id を全部の月で通し番号にした | 月ごとに 1 から振り直していたため、**8 月の記録に付けたレシート写真が 7 月の別の記録に出てしまう**ことがあった |
| 提出日を「精算書を作った日」にした | 対象月の翌月 1 日固定で、月末に作ると未来の日付が載っていた |
| 印刷の余白を `@page` 側に移した | 2 ページ目以降の余白が 0 で、表が紙の上端に貼り付いていた |
| 表の見出し行・合計欄・振込先・レシート 1 枚を、改ページで分断しないようにした | 記録が多いと途中で切れることがあった |
| 印刷時に背景色を保持するようにした | 環境によって区分チップや総合計の帯の色が飛んでいた |
| レシート写真の読み込みを待ってから印刷するようにした | 写真が間に合わず、添付が空欄の PDF が出ることがあった |
| 写真の取り込みで EXIF の向きを見るようにした | iPhone で撮ったレシートが横倒しのまま載ることがあった |
| 月の入力を空にしたとき、表示と中身を合わせるようにした | 表示は空、中身は今月、というずれが起きていた |

## 手元で確かめる

ブラウザで `index.html` を開き、記録を 2〜3 件（うち 1 件は写真つきの立替あり）入れて
PDF を書き出すのが手軽な確認方法です。記録を 30 件ほど入れると、改ページの見え方も確認できます。
